# references/legal/

Nhóm "Pháp luật" trong `references/_INDEX.xlsx`: văn bản quy phạm pháp luật và văn bản của cơ quan nhà nước. Mỗi lĩnh vực một thư
mục con không dấu (ví dụ van-thu-luu-tru, lao-dong, thi-hanh-an-dan-su); có thể thêm README ngắn ghi phạm vi, người cập
nhật, nguồn chính thống. Tên file `<năm>-<số>-<ký hiệu>_<ten-ngan>.pdf`. Mỗi file một dòng trong chỉ mục, có Ngày kiểm tình trạng
và Mức độ xác minh. Ưu tiên bản tải từ nguồn chính thống (Công báo, cơ sở dữ liệu văn bản pháp luật); ghi đường dẫn nguồn vào chỉ mục.
