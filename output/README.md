# output/

Nơi chứa deliverable hiện hành mà user có thể sử dụng/giao tiếp.

Quy tắc:

- ưu tiên tên file rõ ràng;
- version deliverable khi thay đổi đáng kể nếu project cần;
- không tự ghi đè source gốc của user;
- khi bản mới thay thế bản cũ, có thể chuyển bản cũ sang `archive/` theo chỉ đạo/policy của project.
