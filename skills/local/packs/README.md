# skills/local/packs/

Nơi cài **gói lĩnh vực** (xem `packs/README.md`). Không sửa tay thư mục con do `tools/pack.py` tạo: gỡ hoặc cập nhật bằng
`python tools/pack.py remove|update <tên>` để `.agent/SKILL_INDEX.md` luôn khớp.

Gói cài ở đây là của project này; tạo gói mới trong `packs/` (thư mục nguồn của package), không phải ở đây.
