# skills/local/project/

Hướng dẫn hoặc cách dùng mẫu riêng của dự án/đơn vị, nếu thật sự hữu ích.

Ví dụ: cách lập một báo cáo đặc thù hoặc sử dụng biểu mẫu nội bộ. Quy định nghiệp
vụ có thẩm quyền vẫn nằm ở nguồn/reference; skill có thể trỏ tới nguồn đó thay vì
chép thành một bản chính sách thứ hai. Không đưa lịch sử phiên vào skill.

Cập nhật `.agent/SKILL_INDEX.md` khi thêm hoặc thay đổi đáng kể (đường dẫn tính từ
project root). Không cần tạo skill riêng nếu native hoặc shared skill đã đáp ứng.
