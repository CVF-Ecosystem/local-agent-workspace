## Notes

Prefer stable or frequently used sources; there is no need to list every temporary file.
Paths may point to an older structure; sources do not have to be moved into `references/`.
Update the index when a source changes location or is no longer used. If the user names
the source directly, open it without going through the index.

Templates bundled with a skill are examples; they do not become approved business sources on their own.
