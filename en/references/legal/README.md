# references/legal/

The "Pháp luật" (legal) group in `references/_INDEX.xlsx`: legal normative documents and documents of state bodies. One sub-folder
per domain without accents (for example van-thu-luu-tru, lao-dong, thi-hanh-an-dan-su); it may have a short README
with the scope, who updates it and the official source. File names `<year>-<number>-<symbol>_<short-name>.pdf`. One index row per
file, with a status check date and a verification level. Prefer copies from official sources (the Official Gazette, legal
databases); record the source URL in the index.
