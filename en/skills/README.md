# skills/

A library of guidance and extra resources managed by the user.

## Choose by task

Native, local, external or working directly can each be a good choice. Weigh the fit with the
source, the output, the language and the tools actually available; there is no need to favor one
group just because of who provides it. Check `.agent/SKILL_INDEX.md` (from the project root) when
you need to discover options; if you already know a useful skill, you can open its guidance directly.

A skill is not a whole process that must be run. For example, fixing one sentence usually does not
need the document-drafting skill; creating a Word file can combine business guidance with the
formatting tools already available. There is no need to read the whole library or all the examples.

## Areas

- `local/shared/`: guidance reused across many projects; eleven newly written skills.
- `local/project/`: project-specific guidance, only when really needed.
- `external/`: skills imported from outside sources, keeping their origin and accompanying terms.
- `inbox/`: an optional temporary place, not a required approval step.

When adding or substantially editing a skill, update the index with its purpose and notable dependencies.
Do not repeat this when only reusing a skill. The user keeps control of the library; the agent chooses
a suitable way of using it within the scope given.

This library is read like project files and is not registered natively with any app.
There is no need to copy native skills here just to complete a set. Details for users:
`docs/en/SKILLS_GUIDE.md` (from the project root).

## File naming

File and folder names are identical in the Vietnamese and English trees; only the content language differs.
That is why the English version in `en/` can overlay the same paths.
