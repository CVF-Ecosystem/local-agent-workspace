# Co-authoring a document

This is an optional choice, not the default process. If the user has already supplied sources and a
clear request, just draft; do not open this process.

## When to offer it

Only when the document is large, has many parts, and the user is unclear on content or wants to think
it through together. Describe the process once in two or three sentences and ask whether they want to
use it or have you draft straight away. If they decline, draft straight away and do not bring it up again.

## Four steps, each with a limit

1. **Gather context (one round).** Ask in one message: type of document, readers and what they must
   do after reading, mandatory template or format, constraints. Invite the user to paste or supply
   source files in whatever way is convenient. Ask at most one more round, only for gaps that affect content.
2. **Settle the outline.** Propose the sections and their order, say briefly what each will contain
   and which source backs it. The user approves or adjusts once.
3. **Draft section by section.** Draft the sections with the most key content first; small ones later.
   At most one revision round per section based on feedback. Leave a "needs confirmation" cell where
   there is no basis; do not fill it yourself. Small sections can be delivered together.
4. **Final review (one round).** Read the whole thing for: contradictions between sections,
   inconsistent terms, ideas missing against the outline, figures or names that do not match sources.
   Report briefly and fix what is certain; put anything uncertain to the user.

## Reader's-eye check (only when asked)

List 4 to 6 questions the real target reader would ask and see whether the document answers them.
Add or flag what is missing. Do it once, without sub-agents.

## Finishing

When the outline is settled, the sections approved and the final review done, stop. State what is
still "needs confirmation". Do not add appendices, summaries or alternative versions on your own. If
Word/PDF is needed, use a suitable formatting tool once the content is approved.
