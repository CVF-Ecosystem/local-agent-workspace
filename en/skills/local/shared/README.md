# skills/local/shared/

Shared skills written for office work.

- `office-documents/`: business documents, with three short reference templates.
- `html-reports/`: HTML reports, with two offline templates.
- `vietnamese-editing/`: style editing of Vietnamese text when needed.
- `document-comparison/`: comparing two versions of a document.
- `spreadsheet-check/`: checking a spreadsheet before using its figures.
- `meeting-minutes/`: meeting minutes and summaries.
- `process-mapping/`: step tables, RACI and process diagrams.
- `internal-comms/`: progress reports, announcements, newsletters, FAQs.
- `doc-coauthoring/`: co-authoring a large document (optional).
- `data-charts/`: offline SVG charts and a chart selection guide.
- `vn-admin-documents/`: Vietnamese administrative documents in the proper format (official letter, submission, report, notice).

There is no need to read all eleven or apply them in a chain. Each skill has a `SKILL.md` that describes
when it helps; resources inside are opened only when relevant. Illustrative templates are not the
project's approved rules. Source of the ideas: `docs/en/SOURCES_AND_REFERENCES.md` at the project root.

When adding new guidance, favor what the agent does not already have: real templates, experience or
task-specific details. Record it in the skill index on significant changes, not on every use.
