# Output example: a table comparing two versions

An illustration; content is fictional.

## Input

A file-intake procedure, the old version (2025) and the new version (2026).

## Output

**Summary:** 4 significant changes; the most important are the shorter handling time and the change of approver.
In addition the new version renumbers sections 4-7 and fixes a few spelling errors, with no change of meaning.

| Section | Old | New | Type | Impact (inferred) |
|---|---|---|---|---|
| 3.2 Handling time | "05 working days" | "03 working days" | Changed | Handlers must finish 02 days sooner |
| 3.4 Approver | "Head of department" | "Deputy director in charge" | Changed | Needs confirmation: is authority delegated back to the head of department? |
| 5 Forms | None | Adds "Request for supplement" | Added | Incomplete files must use this form |
| 6.1 File retention | "02 years" | Removed | Removed | Needs confirmation of the current retention period |

**Could not be compared:** the table in Annex 2 of the old version is a scanned image and could not be read.

## What to notice

Changes to figures, deadlines, roles and authority come first. Impact is written only when the text gives a
basis; otherwise "needs confirmation". The part that could not be compared is stated.
