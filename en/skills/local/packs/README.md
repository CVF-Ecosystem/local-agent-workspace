# skills/local/packs/

Where **domain packs** are installed (see `packs/README.md`). Do not edit the subfolders created by `tools/pack.py` by hand:
remove or update them with `python tools/pack.py remove|update <name>` so `.agent/SKILL_INDEX.md` always matches.

Packs installed here belong to this project; author new packs in `packs/` (the package's source folder), not here.
