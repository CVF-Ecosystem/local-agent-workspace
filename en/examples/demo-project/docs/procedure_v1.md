# File intake procedure (version 1, fake data)

1. The intake officer checks that the file has all the papers on the list.
2. If something is missing, guide the applicant to supplement it the same day.
3. Enter the file into the system and issue an intake code.
4. Pass the file to the handling unit within 1 working day.
5. The handling unit completes it within 5 working days.
6. The intake officer notifies the applicant of the result.
