# Adapter cho Claude

@AGENTS.md

`AGENTS.md` là hướng dẫn chung. Dòng nhập (import) ở trên chỉ là tiện ích cho môi trường hỗ
trợ nó, không bảo đảm mọi giao diện Claude đều đọc file cục bộ. Khi cần, yêu cầu agent mở
`AGENTS.md` trực tiếp bằng quyền truy cập file đang có, hoặc dán đoạn hướng dẫn trong
`docs/HUONG_DAN_TAO_PROJECT_MOI_VI.md` vào phần hướng dẫn của Project.
Chỉ ghi vào đây những điều thật sự riêng cho Claude; không lặp lại hướng dẫn chung.
